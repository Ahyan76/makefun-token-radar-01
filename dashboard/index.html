Pre-token protocols, ranked by what a token would be worth if the record stood as it is.

How a row is scored

Implied value = TVL × category multiple × growth × maturity × chains. The category multiple is the median market-cap / TVL of live-token protocols in the same category (3+ comparables, else the global median). Growth is the 7-day TVL change; maturity the days since first listed. No name is special-cased. A protocol records no token — never that it has none.
